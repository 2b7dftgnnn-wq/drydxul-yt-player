# DRYDXUL Official YouTube Player Gateway

This repository hosts the static, zero-credential HTML gateway for the official YouTube IFrame Player API.
Designed exclusively for secure, sandbox-compliant playback within DRYDXUL on Samsung Tizen OS.

- **Zero Secrets / Zero Credentials:** Standalone client-side HTML/JS only.
- **Strict YouTube IFrame API:** Uses official Google YouTube embedded player.
- **Strict Content Security Policy (CSP) & Referrer-Policy:** Enforces origin-only referer and restricted asset domains.
